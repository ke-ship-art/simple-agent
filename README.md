# Simple Agent

供个人使用的中文 Windows 桌面文件智能体。配置自己的模型，选择本地文件夹，在聊天中指挥 AI 读取和修改文件，也可手动编辑并查看修改记录、撤销最近一轮操作。

## 运行便携版

Git 仓库仅包含源码、测试、文档和必要资源，不包含运行包或开发依赖。若下载的是 GitHub 源码，请按下文「开发」步骤构建；已有运行包的使用方式如下。

解压 `release/Simple-Agent-0.2.1-win-x64.zip` 到可写目录，运行其中的 `Simple Agent.exe`。需要 Windows x64；无需安装 Node、Python 或 Office。首次启动没有预置账号或密钥。

1. 打开「模型设置」，添加接入配置。
2. API Key 接入填写密钥；自定义服务填写完整 Base URL，例如 `http://127.0.0.1:11434/v1`。公网地址使用 HTTPS。局域网 HTTP 需勾选信任，仅对当前地址及解析出的私网 IP 授权；无密钥模式适合本地兼容服务。
3. 从供应商目录选择模型，或手动填写模型 ID、上下文长度、输出上限和视觉能力，点击「添加模型」。可以测试连接、启停或编辑已添加的模型。
4. 点击「选择工作区」。聊天框旁的菜单只显示已添加且启用的模型，附带所属接入名称。切换模型保留会话，从下一轮开始使用新模型。
5. 输入任务。使用 `@` 搜索并引用文件，或在文件工具栏点击 `@`。引用只传递路径，内容由 AI 按需读取。
6. 工具记录可展开；「修改记录」显示文本差异及办公文件内容变化。「停止任务」保留已完成修改；「撤销最近一轮」恢复对应快照。

同一供应商可保存多个接入配置，密钥和 OAuth 凭据分别管理。ChatGPT、Anthropic、GitHub Copilot、OpenRouter 提供 SDK 内置 OAuth 入口；浏览器授权、设备码及手动回填按供应商流程显示。模型服务的订阅权限与模型可用性由供应商决定。

### 代理与 ChatGPT 登录

模型设置顶部有「网络与代理」。新配置默认直连；需要代理时自行启用并填写实际端口，再点击「保存代理设置」。旧版已经保存的代理设置继续保留。设置只保存在本应用，立即生效并在重启后保留，不修改 Windows 代理或环境变量。本机 `localhost`、`127.*`、`::1` 服务与授权回调绕过代理。

ChatGPT 登录：添加 OpenAI / ChatGPT 接入，选择「订阅 / OAuth 登录」，保存接入配置后点击「登录订阅账号」。网页显示成功后还需要等待应用换取并保存凭据；以应用显示「登录成功」为准，再添加模型。「保存并测试网络」测试当前已保存的接入配置：已添加模型时测试实际模型调用，否则测试对应目录接口。目录可达不等于模型权限通过，认证、模型 ID、协议和网络错误分别显示。测试实际调用会使用该配置的凭据及少量模型额度。

### 推理强度

聊天模型菜单旁可选择推理强度，菜单只显示当前模型的有效档位。默认中等；每个模型独立记住选择，新会话和重启后继续使用。任务开始后固定档位，所有工具循环保持一致，回复标题记录实际档位。运行期间不能切换模型或强度。

内置模型从 SDK 读取能力和映射。自定义模型需先勾选「推理模型」，再勾选「支持强度调节」并配置服务支持的档位；默认不启用调节。OpenAI 兼容服务需要支持对应的 reasoning 参数，非标准服务不自动推测参数格式。旧版内置模型自动补全能力和默认强度；旧版自定义模型需明确声明可用档位。历史回复不补写强度。

强度较高通常耗时更长、消耗更多额度。推理与回答共享输出上限；预算式模型为可见回答保留至少 1024 token，因此启用推理时上限至少为 2048。预算不会自动扩大输出上限；较高强度可能受上限限制。达到上限或没有返回可用回答时会明确提示，可提高输出上限或降低强度后重试。

## 文件能力

| 格式 | 支持的操作 |
|---|---|
| UTF-8 文本、代码 | Monaco 编辑与查找、读取、新建、精确唯一替换；保留 BOM 和原有 LF/CRLF |
| DOCX | 段落、表格单元格的结构化内容预览与编辑；修改原包的目标文字节点，保留其他包条目及样式节点 |
| XLSX | 工作表、合并区域、值和公式预览；按地址编辑单元格，保留样式和其他结构；按依赖失效公式缓存，保留可确认未受影响的缓存并标记重算 |
| PDF | 页面预览、文字提取、中文原生批注与添字、追加合并、页面重排、提取或导出页面到新文件 |

Word 预览是内容视图。等长跨 run 替换按 Unicode 字符保留格式分布；长度变化且跨不同格式时默认拒绝，可明确勾选采用首 run 样式并审核差异。制表符、软换行和空白保持原始语义。复杂域、修订、内容控件、绘图等所在段落拒绝编辑。Excel 不提供计算引擎；修改后的公式显示「待重算」，请在 Excel 或兼容软件中打开计算。共享、数组、数据表公式及受保护工作表拒绝编辑，合并区域只允许修改左上角。

PDF 的「重排 / 提取」修改当前文件；「导出页面」使用同一页面序列创建新 PDF，不覆盖已有文件。多次导出可完成拆分。点击预览定位批注/添字坐标，坐标以 PDF 点计、左下角为原点，旋转页面会转换点击坐标。扫描 PDF 通过 `read_pdf` 将指定页面渲染为图片，发送给当前视觉模型；文字模型会明确提示切换，已有识别文字保留。

首版限制：单文件 50 MB，文本编辑 2 MB，OOXML 解压总量 64 MB / 10,000 条目，单部件 32 MB，单次工具读取至多 200 行或条目，PDF 视觉读取每次最多 3 页、图片最长边 1600 像素。全应用同时运行一个任务，每轮最多 20 次模型调用；连续 4 次相同工具请求会暂停；上下文接近预算时压缩请求中的较早内容，原始历史可通过 read_history 找回。图片独立保存，历史只保留引用、来源和页码；每次至多按需加载 3 张，支持 read_resource 重新引用。容量不足或超时明确暂停。

旧版 `.doc/.xls`、宏文档、加密或签名文件、完整 Office 排版、终端执行、MCP 与插件不在首版范围内。

## 数据与恢复

用户数据默认保存于 `%APPDATA%\SimpleAgent`：

- `state.backup.json`：上一代有效配置；主文件损坏时保留损坏副本并恢复备份。
- `resources/`：按 SHA-256 去重的页面图片；删除会话先进入回收站，永久清理只移除无其他引用的资源。
- `state.json`：接入配置的非机密信息、模型、工作区、会话、工具结果的图片引用和恢复日志；包含校验和与中断任务状态。
- `credentials.enc`：Electron `safeStorage` 加密后的 API Key / OAuth 凭据。凭据与当前 Windows 用户关联，复制至另一个账户不能直接解密。
- `backups/`：每次写入前的原文件字节快照。未自动清理，以支持重启后撤销。

所有路径由主进程验证：拒绝绝对路径、上级跳转、Windows 特殊名称、符号链接和目录联接；再次检查工作区根目录。读写使用 SHA-256 版本，写入先保存快照及日志，再用同目录临时文件替换；Windows 短暂占用有限重试，每次重试重新检查版本。撤销前检查文件是否仍与写入结果一致，遇到后续手动或外部修改会停止。未保存编辑会阻止 AI 写入对应文件，也会在退出时提示。

会话和快照包含你处理过的文件内容，请按本地文件管理。发送任务即允许应用把任务所需内容发给所选接入服务；应用不上传整个工作区。日志和返回错误隐藏已配置的密钥。

## 开发

使用 Node 24.14 或以上版本（代理功能需要 `http.setGlobalProxyFromEnv`），在项目目录运行：

```powershell
npm ci
npm run dev
```

若依赖安装阶段没有下载 Electron，可运行 `node node_modules/electron/install.js`。开发启动及构建自动复制 PDF.js 的字体、CMap 与 WASM 资源至本地静态目录；不依赖 CDN。

```powershell
npm run typecheck
npm test
npm run build
npm run test:e2e
npm run package
```

`npm run package` 生成 Windows x64 ZIP 和 `release/win-unpacked`。桌面端到端测试使用 Electron、自建本地模拟模型服务及隔离的数据目录；无需下载 Playwright 浏览器。验证打包后的程序可设置：

```powershell
$env:SIMPLE_AGENT_PACKAGED_EXE = (Resolve-Path 'release/win-unpacked/Simple Agent.exe').Path
npm run test:e2e
Remove-Item Env:SIMPLE_AGENT_PACKAGED_EXE
```

会话列表提供重命名、归档、恢复及回收站。文件修改审核提供文件列表、行级高亮、并排视图、修改统计和整轮接受/撤销；遇到外部修改拒绝覆盖。搜索在 Worker Thread 中运行，支持取消、进度、大小上限和排除规则。

主进程通过 Node `http.setGlobalProxyFromEnv()` 将应用代理统一应用到 `fetch` 和 HTTP(S) 请求，包括 OAuth 换取凭据、刷新、模型目录、连接测试及流式聊天。代理不可用时返回错误，不自动切换直连；本地服务按绕过规则直连。依赖安装或打包所需的网络访问由开发环境提供。

## 代码布局

项目已精简：保留当前源码、测试、文档、字体及许可证，`release/` 仅保留最新运行 ZIP 和校验清单。旧版本包、重复源码 ZIP、`node_modules/`、`out/`、测试临时数据和构建日志均可重新生成，已清理。继续开发先运行 `npm ci`；开发启动和构建会自动恢复 PDF.js 静态资源。需要源码压缩包时，在恢复依赖后运行 `node scripts/package-source.mjs`。

- `src/main/models.ts`：pi-ai 协议接入、目录、连接测试、独立凭据与 OAuth 交互。
- `src/main/network.ts`：代理地址校验、进程内请求路由、网络测试及连接错误提示。
- `src/main/agent.ts`：流式循环、参数验证、顺序工具执行、停止及历史图像兼容。
- `src/main/workspace.ts`：路径边界、版本冲突、写入快照、日志恢复与撤销。
- `src/main/documents.ts`：文本、DOCX、XLSX 与 PDF 文件适配器。
- `src/main/store.ts`：原子持久化与加密凭据存储。
- `src/main/index.ts` / `src/preload/index.ts`：主进程受限 IPC、沙箱窗口与 PDF 渲染服务。
- `src/renderer/src/main.tsx`：中文三栏界面、编辑器、模型设置与聊天。
- `tests/`：文件与办公文档、模型认证、智能体及 Electron 端到端测试。

渲染进程开启沙箱和上下文隔离，不提供 Node、任意文件访问或命令执行。模型调用和文件操作都在主进程，事件携带会话 ID 与任务 ID。

开发互操作测试需要 Python 3 和 openpyxl；可用 `SIMPLE_AGENT_PYTHON` 指定解释器。运行包本身不需要 Python 或 Office。

## 验证状态

详见 `docs/VERIFICATION.md`。本地模拟服务验证实际 pi-ai 调用和工具闭环；OAuth 交互、回填、刷新及退出使用模拟授权测试。当前没有使用用户真实账号或密钥访问四家 OAuth 服务，因此不把这些供应商标记为真实登录验证完成。

中文 PDF 字体为 Noto Sans CJK SC，许可证位于 `resources/OFL.txt`；其他依赖保留各包许可证。

0.2.0 的整改明细、兼容性与验证入口见 [整改报告](docs/RELIABILITY-AUDIT.md)。升级会自动迁移旧历史中的图片；升级后不要用旧版本写入同一份用户数据。

0.2.1 的前后端体验修复与验证范围见 [体验审查报告](docs/EXPERIENCE-AUDIT.md)。聊天草稿按会话保存到本机；Ctrl+S 保存文件；连接测试支持取消；Excel 复制粘贴保留单元格内换行及引号。
