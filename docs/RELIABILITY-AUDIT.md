# 0.2.0 可靠性整改报告

复核与实现日期：2026-10-14 至 2026-10-15。基于现有 0.1.2 项目原地整改，没有另建智能体。pi-ai 仍为 0.99.2，Electron 44.5.1 / 内置 Node 24.21.0。

## 实际缺陷与修复

| 审计项 | 独立复核发现 | 实现与边界 |
|---|---|---|
| 1 图片与上下文 | Base64 长期驻留 context，每步整份序列化；仅在容量不足时停止 | `Resources` 按 SHA-256 独立保存图片，历史只存引用、来源、版本、页码及摘要。启动迁移旧图片。每次请求只按需载入最近请求的最多 3 张；`read_resource` 可重读旧图。请求级压缩保留原始历史，`read_history` 支持逐条、逐字符页找回完整内容。按文本字符类别与图像成本保守估算，预留工具/系统提示与输出预算。仍非供应商精确 tokenizer |
| 2 多工具与一致性 | 同响应的两个旧版本编辑会被自己前一次修改阻断 | 连续 edit_file 帧按规范路径归组；同文件同快照、唯一且互不重叠的文本范围以原快照坐标合并；不同段落/单元格可合并。表名和 ID 的同单元格别名也检查。重叠、不同版本及依赖性修改拒绝，返回重新读取要求。跨文件批次有持久事务，失败回滚，异常重启继续恢复；遇外部修改留下明确冲突，绝不强行改版本 |
| 3 Excel 分页 | 每张表重复使用同 offset，短表与长表互相干扰 | `paginateExcel` 支持 sheet 名或 ID 的独立游标；默认按工作表顺序串联非空单元格，统一跨表 offset。返回全局及各表分页信息 |
| 4 Word | 替换结果塞入首 run；tab/br 不作为正文提取 | 识别 w:t/tab/br/cr/软连字符、不换行连字符及保留空白。等长按 Unicode code point 分配回原 run；长度变化且跨不同格式默认拒绝，明确 first-run 策略才允许。保护复杂域、修订、绘图、内容控件与文本框。只识别 Word 命名空间的段落，防止误改 drawing 文本。语义 Diff 包含段落前后及 run 基础样式 |
| 5 Excel 缓存 | 无差别清空所有公式 v 值 | 识别 A1 引用、范围、跨表和传递依赖，清除可能失效缓存，保留可证明独立的缓存。动态/外链/命名/结构化/未知函数/共享数组等依赖按不透明处理并传播失效；达到复杂度上限保守扩大失效集合。删除失效 calcChain 及关联，设置自动/打开时重算。应用不计算公式，失效缓存保持空值 |
| 6 PDF Unicode | 未验证嵌入字体字形，可能输出 .notdef | 添加前检查字体覆盖；只有完整字符串可由备用字体覆盖才使用备用字体。否则列出缺失字符及 U+ 编号，整次修改不写入；可改用保留 Unicode 的原生批注。不会自动丢字或替换字符 |
| 7 PDF 进程恢复 | 隐藏窗口只创建一次，崩溃后必须重启 | `PdfService` 处理异常退出、旧发送者隔离、请求超时/取消、资源销毁及新代窗口重建。启动约 15 秒、任务 60 秒超时；每分钟最多 3 次启动，连续失败明确提示。关闭期间不重建。失败请求不静默重试 |
| 8 全文搜索 | 主进程 split 全文并逐行扫描，事件循环可能阻塞 | Worker Thread 中按 64 KB 流读取，单行预览至多 500 字，UTF-8 严格解码。支持定向取消、进度、排除 glob、文件/命中/遍历上限、二进制及凭据文件排除。主线程不进行大文件正文扫描 |
| 9 LAN 端点 | HTTP 只接受 localhost，不能连接可信 NAS/WSL2 | 当前接入显式 trustedHttp 授权后，仅允许 RFC1918/ULA 私网地址。保存时记录解析 IP，每次访问重新验证，原生 HTTP 固定连接批准的 IP 并核对 socket 实际对端。阻止地址变化、混合地址、特殊地址和重定向；LAN 绕过代理。公网要求 HTTPS。Gemini 使用 AsyncLocalStorage 限定 fetch 路由，兼容其不接受自定义 fetch 的适配器 |
| 10 网络测试 | 默认强依赖 7897，所有服务都测 OpenAI 登录域 | 新用户默认直连，已有代理不变。测试已选接入；有模型时进行实际调用，否则检查相应目录端点。Anthropic 使用 /v1/models，OpenAI 兼容/Ollama 使用对应 /models。分别报告网络、认证、模型 ID、协议、额度和超时；模型调用测试使用同一强度参数 |
| 11 会话管理 | 仅能新建及切换 | 重命名（不会被首条消息覆盖）、归档、恢复、回收站删除及显式确认永久清理。共享图片引用与恢复备份均为清理根；资源写入和清理串行，新任务开始时暂停清理。工作区文件与撤销快照不随会话删除 |
| 12 Diff | 文本 patch 及 Office 摘要，缺少逐文件审核 | 修改集文件列表、行级高亮、前后并排、增加/删除统计、整轮接受及撤销。Office 生成段落/单元格/公式缓存/页面操作语义 Diff，并在 prepared 日志中持久化。审核和撤销核对实际文件及未保存内容；Diff 计算异步且限制复杂度/大小，超限拒绝本次写入。接受表示确认已经自动保存的修改，不再次写文件 |
| 13 Office 体验 | Word 扁平文本；Excel 截断前 1000 个单元格 | Word 段落/表格结构及粗体/斜体/下划线基础预览。Excel 工作表切换、单元格列表虚拟滚动、地址筛选、Tab/换行批量粘贴及范围 TSV 复制；单次粘贴最多 100 格。高级排版、共享/数组公式仍保护，不伪装完整 Office 渲染 |

## 额外修复与保护

- 启动准备阶段即占用任务锁；等待认证时可取消。对忽略 signal 的模型请求也能结束等待，迟到输出不会继续写入聊天。
- 连续 4 次相同工具请求暂停；20 轮模型调用和单响应 32 工具上限仍在。重复工具编号、未知工具和错误参数不执行；无效编辑批次不能漏执行后面的有效兄弟操作。
- 工具检查取消与 60 秒预算；写入前检查 signal。原子提交阶段不会通过 Promise.race 抛下后台写入。模型请求保留 180 秒超时。
- 中断时补齐缺失 toolResult，恢复协议帧，明确结果未确认而非重复执行。任务最终状态持久化完成后才显示空闲。
- state.json 增加校验和、上一代有效备份；损坏主文件单独保留，尝试恢复有效备份。没有有效代时保留数据并明确报错，不能默默清空配置。
- 凭据更新先写独立加密修订，再提交配置引用。保存失败/进程中断不会把新密钥配到旧地址。历史加密修订为配置备份保留，退出登录/删除接入会清除该接入的全部修订；错误脱敏覆盖修订凭据。凭据仍只通过 safeStorage 保存。
- 未保存内容保护覆盖嵌套工作区别名。快照校验先于撤销首个文件；外部变更、损坏快照和恢复不确定状态明确停止，保留文件及日志。
- 常见凭据路径需用户本轮显式引用/指定，文档内诱导不能替代授权。工具没有终端、任意网络请求、MCP 或外部命令入口。无法通过提示词单独保证所有语义上的越权均被识别，路径/版本/端点/工具白名单才是执行边界。
- Office 解压校验真实 ZIP 中央目录与实际解压长度，限制总 64 MB、单部件 32 MB、10000 条目，拒绝伪造长度、路径异常、外部实体、宏/签名等不可靠编辑。
- Electron 沙箱、上下文隔离、关闭 Node、主窗口/主 frame IPC 校验保持。生产 CSP 不开放 localhost 网络，开发模式单独开放 HMR；PDF.js 关闭 eval 与 XFA。

## 验证与证据

最终执行结果及命令见 [VERIFICATION.md](VERIFICATION.md)。单元测试覆盖 12 个文件；新增测试使用独立临时副本和本机 HTTP/SSE 模拟模型。Electron 场景覆盖真正窗口、preload、pi-ai 适配器与磁盘文件，包含 forcefullyCrashRenderer 及跳过正常退出回调的 app.exit(77) 异常退出。

Office 互操作除 XML/字节断言外，实际使用 Microsoft Excel 16.0 打开测试副本并 CalculateFullRebuild：直接依赖 B1=8，链式 C1=9，跨表 A1=18，独立 D1=101。保存后 openpyxl(data_only=True) 再次读出正确值。Excel 打开前，受影响缓存为 None，独立缓存 101/100 保留。

公式策略依据：Microsoft 说明 `<v>` 是上次计算的缓存，calcChain 只记录计算顺序而非依赖树。因此不能仅凭 calcChain 推断有效性；本实现只在能够识别依赖时保留缓存，其余保守失效。

- [Microsoft：Working with the calculation chain](https://learn.microsoft.com/en-us/office/open-xml/spreadsheet/working-with-the-calculation-chain)

## 限制与兼容性

1. 升级可读取 0.1.2 数据并迁移图片。新图片引用、事务状态和凭据修订均为新增数据，**不要降级后让 0.1.2 写入同一份用户数据**；回退需使用升级前独立备份。首次迁移会保留 state.before-0.2.0.json；凭据仍在当前加密存储，撤销快照不删除。该副本包含旧聊天历史，需按私密数据管理。没有升级 pi-ai 或改变模型协议版本。
2. Office 仍为内容级编辑。高级格式不计算/不重建；不透明公式可能被保守失效。重算标记不能迫使所有第三方阅读器计算，data_only 读取失效公式会得到 None，直到 Excel 重算。
3. 多文件事务是可恢复事务，不是文件系统全局原子提交。外部程序仍可能观察提交中间态；若回滚期间出现外部修改，可能保留部分结果并明确冲突。Windows 不提供本项目可用的通用跨进程版本 compare-and-swap；持续恶意目录替换不等同于正常并发修改，未声称具备操作系统级隔离。
4. Office/PDF 部分解析与保存仍在主进程，有压缩/文件/复杂度上限，极复杂文档仍可能产生短暂停顿；全文搜索已完全移出主线程。不是 Office 全量渲染引擎。
5. 上下文压缩是可恢复的确定性摘要/截取，模型必须按需调用 read_history/read_resource；不声称摘要能无损包含所有语义。估算器不是供应商 tokenizer，最终超限仍可能由服务报错。
6. 没有使用真实供应商账号或密钥调用付费模型。本地/模拟协议、DNS/LAN 授权与重绑定拒绝均有验证，但未连用户实际 NAS/WSL2/vLLM。HTTPS 端点要求可信公共 DNS（或回环），自签名证书/特殊网络地址不自动放行。
7. PDF 字体覆盖不等于完整支持所有语言排版。缺字、制表符或复杂字体需求会明确拒绝添字；原生 Unicode 批注可保留文本。没有逐块接受/拒绝功能，审核以整轮文件集为单位。
8. 会话软删除可恢复，永久清理需二次确认；文件撤销快照未自动过期清理，磁盘使用可能增长。孤立图片在启动时有 24 小时宽限后清理，避免异常退出后立即删除可恢复资源。

## 主要功能验收步骤

1. 用测试文件夹，配置本地兼容模型或自己的接入，测试所选配置；新配置默认无代理。
2. 要求在同轮改同文件两个不同位置，查看文件差异，然后撤销；用旧版本号或外部编辑验证冲突。
3. 读取扫描 PDF 多页，重启后继续并请求重看旧图；确认用户数据目录 resources 存在，state.json 没有 Base64 图像正文。
4. 编辑含粗体/斜体、tab/br 的 Word；长度变化跨格式默认拒绝。检查预览和修改记录中的样式策略。
5. 编辑跨 Sheet 工作簿的输入，检查独立缓存仍保留、依赖公式为空待重算，再在 Excel 打开计算。
6. 在会话列表完成重命名、归档/恢复、删除/恢复；在工作区搜索中查看进度并取消。
7. 开发环境执行 npm run typecheck、npm test、npm run build、npm run test:e2e。Office Python 路径可用 SIMPLE_AGENT_PYTHON 指定；Excel 实机验证脚本见 scripts/verify-excel.ps1。
